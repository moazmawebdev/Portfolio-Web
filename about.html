About

Building my craft, one project at a time.

Every project I take on gets the same commitment: finishing what I start, and building it right. Here's a growing set of complete, real projects that show that approach in practice.

I'm Moazma, a frontend developer focused on HTML, CSS and vanilla JavaScript. I got into development because I liked the idea of building something a person could actually open and use — not just a design in a file, but a real page that works in a browser.

Rather than padding this page with claims, I'd rather let the work speak for itself: four complete websites, each built to solve a real brief — a real estate listing page, a restaurant site, a skincare brand and a fitness studio.

My Approach

  • 01

    Start with structure

    Semantic HTML first — the right element for the right job, before a single line of CSS.

  • 02

    Design in the browser

    I build layouts responsively from the start, testing from small screens up rather than shrinking a desktop design down.

  • 03

    Add motion with intent

    JavaScript goes in last, and only where it genuinely improves the experience — never just to prove it can.

  • 04

    Check it everywhere

    Every project gets tested across screen sizes, keyboard navigation and reduced-motion settings before I call it done.
